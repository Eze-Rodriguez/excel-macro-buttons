# 📊 Excel Macro Buttons - *Finance Business App*

## 🚀 Etapas del Proyecto

### ✅ 1ra Etapa:  
Mejoras en los códigos *Macro*, organización y limpieza del archivo.

### 🔄 2da Etapa:  
Transformación y desarrollo del archivo Excel en una App funcional que cumple con estándares de calidad.

---

## ⚙️ Detalles Técnicos

Desarrollaremos códigos de **Excel Macros** para automatizar funciones clave en la gestión financiera de un negocio.

- **Lenguaje de programación:** `Python` 🐍  
- **Bibliotecas utilizadas:** `xlwings` 📦

---

## 💻 Instalación de xlwings en Windows

### 📌 Requisitos Previos

Asegúrate de cumplir con los siguientes puntos antes de comenzar:

- ✅ Microsoft Excel (2016 o superior recomendado)  
- ✅ Python (versión 3.7 o superior)  
- ✅ Acceso a línea de comandos (CMD o PowerShell)

---

### 🧩 Paso 1: Clona el Repositorio

Abre la terminal y ejecuta:

```sh
git clone https://github.com/Eze-Rodriguez/excel-macro-buttons.git
````

> ⚠️ **Nota:**
> Si no tienes `GIT`, descárgalo desde [git-scm.com](https://git-scm.com/downloads).

También puedes descargar el ZIP del repositorio y extraerlo manualmente. Se recomienda usar `git` para mantener el repositorio actualizado fácilmente.

---

### 🐍 Paso 2: Verifica la Instalación de Python

Ejecuta:

```sh
python --version
```

Si no está instalado, descárgalo de [Python.org](https://www.python.org/downloads).
✅ Asegúrate de marcar la opción **"Add Python to PATH"** durante la instalación.

---

### 📦 Paso 3: Instala xlwings

En la terminal, ejecuta:

```sh
pip install xlwings
```

---

### 📂 Paso 4: Habilita xlwings en Excel

```sh
xlwings addin install
```

> 💡 Cierra y vuelve a abrir Excel después de ejecutar el comando.

---

### 🔐 Paso 5: Habilita Macros en Excel

1. Abre Excel y ve a `Archivo > Opciones`.
2. Dirígete a `Centro de confianza > Configuración del Centro de confianza`.
3. En `Configuración de macros`, selecciona:
   🔘 **Habilitar todas las macros** *(puede ser menos restrictivo si lo prefieres)*.

---

### 🛠️ Paso 6: Configura xlwings

* Abre Excel y ve al *add-in* de **xlwings**
* Haz clic en **PYTHONPATH**
* Copia la ruta de la carpeta clonada en el [Paso 1](#🧩-paso-1-clona-el-repositorio)

---

### 🧪 Paso 7: Prueba las Funcionalidades

Presiona los botones dentro del archivo Excel para ejecutar las macros.
Verifica que se ejecuten correctamente y respondan con ventanas emergentes esperadas.

> ❗ Si algo falla, contacta al administrador del repositorio.

---

## ✅ ¡Listo!

Ya tienes `xlwings` instalado y configurado para trabajar con tu archivo de Excel 📈
